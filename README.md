# PELAGIA · 未来海岸

基于 Three.js、React、TypeScript 和 vinext 的可探索滨水城市。支持步行探索、第一／第三人称、汽车驾驶、自行车骑行、游艇航行和街区互动。

[在线体验](https://pelagia-future-coast.right-tern-9700.chatgpt.site/)

## 本地运行

需要 Node.js 22.13 或更高版本，以及 npm。

```bash
npm ci
npm run dev -- --port 3001
```

打开 http://localhost:3001/。浏览器需要支持 WebGL 2，并启用硬件加速。

## 检查与构建

```bash
npm test
npm run typecheck
npm run build
```

`npm run start` 使用 Wrangler 预览生产构建。`.openai/hosting.json` 是现有 Sites 站点关联配置，不包含部署凭据。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动／驾驶／骑行 | WASD 或方向键 |
| 环顾 | 鼠标；无法锁定时按住画面拖动 |
| 加速 | Shift；步行时 Q 切换持续跑步 |
| 跳跃 | 空格 |
| 上下汽车、自行车和游艇 | 靠近按 F；下车前需停稳，游艇还需靠近码头 |
| 汽车漂移 | 空格 + A/D |
| 自行车、游艇制动 | 空格或 X；S 可制动，汽车和游艇继续按 S 可倒退 |
| 坐下／起身 | 靠近座椅按 E |
| 喂海鸥 | 滨水投喂区按 G |
| 出拳 | J；锁定鼠标时也可按左键 |
| 第一／第三人称 | V |
| 鸟瞰 | B |
| 地图 | M |
| 返回入口 | R |
| 暂停／释放鼠标 | Esc |

左侧地点导航可快速前往广场、市集、学校、警局、海鸥投喂点、自行车和游艇码头。打人、撞车或撞人会触发通缉；脱离警方搜索范围并保持一段时间可以解除。公交车在地图中行驶和停靠，暂不开放驾驶。

## 项目结构

- `app/`：页面、操作界面和样式。
- `lib/city/`：城市几何、人物动画、交通、载具物理、海鸥和警方逻辑。
- `public/assets/`：人物、车辆、材质、动作及素材许可。
- `tests/`：移动、碰撞、动画、载具互动和追逐回归测试。

## 素材与许可

人物和部分车辆使用第三方许可素材，建筑、街景以及新增海鸥、自行车、游艇、公交和警局使用项目原创程序几何。详细来源、改编说明及许可见 [素材来源](public/assets/SOURCES.md)、[素材鸣谢](public/credits.html) 和 `public/assets/` 下的许可文件；第三方素材应继续保留其署名与许可。

依赖、构建产物、临时文件和本地环境变量不纳入仓库。
